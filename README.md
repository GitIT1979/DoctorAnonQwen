# DoctorAnon

Обезличивание документов: PDF, DOCX, MD/TXT и изображения.

Персональные данные закрываются белыми плашками — как в кино про «совершенно секретно»:
в PDF скрытый текст при этом физически удаляется, остальной документ остаётся читаемым и
поисковым; в сканах и картинках плашки выжигаются в пикселях.

## Что скрывается

15 категорий, все включены по умолчанию:

| Ключ | Что закрывается |
|---|---|
| `person` | ФИО, инициалы |
| `identity` | паспорт, водительское удостоверение, загранпаспорт, военный билет, свидетельство о рождении, полис ОМС |
| `codes` | ИНН, КПП, ОГРН/ОГРНИП, ОКПО, ОКТМО, ОКАТО, ОКВЭД, СНИЛС |
| `address` | индекс, регион, город, улица, дом, квартира, офис |
| `realty` | квартиры, дома, участки, гаражи; кадастровый номер, площадь; собственность, аренда |
| `contacts` | телефоны, e-mail, мессенджеры |
| `bank` | счета, карты, БИК, названия банков |
| `finance` | суммы, доходы, зарплата, выручка, долги, кредиты, налоги |
| `property` | автомобили, VIN, госномера |
| `employment` | место работы, работодатель, должность |
| `leisure` | санатории, курорты, отели, путёвки |
| `birth` | возраст, дата рождения |
| `kinship` | родство |
| `org` | наименования организаций |
| `docno` | номера документов |

В судебных актах (определяется автоматически) сохраняются названия судов, ФИО судей,
секретарей, представителей сторон, свидетелей, экспертов, прокуроров и иных участников,
наименования организаций-участников и номер дела; скрываются адреса, города, возраст.

## Установка

```bash
python -m pip install -r requirements.txt
# OCR: Tesseract 5 с языками rus и eng
#   Windows: winget install UB-Mannheim.TesseractOCR
```

Русская модель и конфиги Tesseract подхватываются из `_tools/tessdata`, если папка есть рядом
со скриптом; иначе используется системная установка.

## Использование

```bash
python doctoranon.py "документ.pdf"          # PDF -> документ_anon.pdf
python doctoranon.py "акт.docx"              # DOCX -> акт_anon.md
python doctoranon.py "паспорт.png"           # картинка -> паспорт_anon.png
python doctoranon.py "решение.pdf" --mode judicial
python doctoranon.py "папка/" --report report.json
```

Выбор категорий:

```bash
python doctoranon.py --list-categories            # что вообще скрывается
python doctoranon.py doc.pdf --keep org docno     # оставить открытым
python doctoranon.py doc.pdf --only person address
python doctoranon.py doc.pdf --ask                # показать найденное и спросить
```

Полный список ключей: `python doctoranon.py --help`.

## Проверка

После обработки PDF переоткрывается и проверяется: скрытых значений нет ни в извлечённом тексте,
ни в сырых потоках файла. Метаданные очищаются.

## Ограничения

- ФИО ищутся эвристиками (отчество, суффиксы фамилий, справочник имён, ролевые маркеры):
  редкая фамилия без отчества может не распознаться — критичные документы просматривайте глазами.
- OCR ошибается на косых и шумных сканах.
- Даты событий (не рождения) по умолчанию не скрываются.

Подробные правила — в [ПРАВИЛА_АНОНИМИЗАЦИИ.md](ПРАВИЛА_АНОНИМИЗАЦИИ.md).
