# DoctorHide — правила обезличивания

Программа: `doctorhide.py` (Python 3.9+, PyMuPDF, Pillow, python-docx, Tesseract 5 с `rus`+`eng`).

## Форматы и что происходит с файлом

| Вход | Выход | Механика |
|---|---|---|
| PDF с текстовым слоем | `<имя>_anon.pdf` | Белые плашки. Скрытый текст **удаляется** из файла (не «заклеивается») — под плашкой искать нечего. Остальной текст остаётся текстом: файл читается, ищется, копируется. |
| PDF-скан (без текстового слоя) | `<имя>_anon.pdf` | Страница распознаётся Tesseract, области выжигаются в том же растре и страница собирается обратно 1:1 по вёрстке. Текстового слоя не добавляется. |
| PNG / JPEG / TIFF / BMP / WEBP | `<имя>_anon.<ext>` | Tesseract → белые плашки выжигаются в пикселях, формат и размер сохраняются. |
| DOCX | `<имя>_anon.md` | Конвертация в Markdown (заголовки, списки, таблицы), значения → `[censored]`. |
| MD / TXT | `<имя>_anon.<ext>` | Значения → `[censored]`. |

Плашки ставятся как в кино: ровный белый прямоугольник, подчёркивания и границы таблиц,
случайно попавшие под плашку, восстанавливаются поверх белого.

## Категории

Скрываются по умолчанию все. Список: `python doctorhide.py --list-categories`.

| Ключ | Что скрывается |
|---|---|
| `person` | ФИО: фамилия, имя, отчество, инициалы, ФИО после ролевых маркеров |
| `identity` | Паспорт (серия/номер, код подразделения), водительское удостоверение, загранпаспорт, военный билет, свидетельство о рождении, полис ОМС |
| `codes` | ИНН (с проверкой контрольного числа), КПП, ОГРН/ОГРНИП, ОКПО, ОКТМО, ОКАТО, ОКВЭД, СНИЛС |
| `address` | Индекс, регион, город, улица, дом, корпус, квартира, офис |
| `realty` | Квартиры, дома, участки, гаражи, машино-места; кадастровый номер; площадь; права — собственность, аренда, безвозмездное пользование |
| `contacts` | Телефоны, e-mail, мессенджеры |
| `bank` | Расчётные и корреспондентские счета, карты, БИК, названия банков |
| `finance` | Суммы, доходы, зарплата, выручка, задолженность, кредиты, налоги, пенсии |
| `property` | Автомобили и прочее имущество, VIN, госномера |
| `employment` | Место работы, работодатель, должность |
| `leisure` | Санатории, курорты, отели, путёвки |
| `birth` | Возраст («45 лет»), дата рождения |
| `kinship` | Сын, дочь, мать, отец, супруг(а), брат, сестра, опекун + имя |
| `org` | Наименования организаций: ООО/АО/ПАО/ИП, госорганы, инспекции, управления |
| `docno` | Номера документов «№ …», длинные номера (сертификаты) |

## Судебные акты

Режим включается сам (`--mode auto`) по маркерам: решение, постановление, приговор, «дело №»,
истец/ответчик, прокурор, судья, апелляция/кассация.

В судебном акте **не скрываются**: названия судов, ФИО судей, секретарей, представителей сторон,
свидетелей, экспертов, прокуроров и иных участников, наименования организаций-участников,
номер дела.

**Скрываются**: возраст, дата рождения, адреса, города. ИНН/ОГРН/СНИЛС/паспорт скрываются
по умолчанию; флаг `--court-keep-ids` оставляет их (типично при публикации актов с ИНН организаций).

## Выбор пользователя

```powershell
python doctorhide.py --list-categories              # что вообще скрывается
python doctorhide.py doc.pdf --keep org docno       # эти категории оставить открытыми
python doctorhide.py doc.pdf --only person address  # скрыть только эти
python doctorhide.py doc.pdf --ask                  # показать найденное и спросить
```

`--ask` печатает, какие категории и сколько раз найдены, и спрашивает, что оставить открытым.
Enter — скрыть всё.

## Запуск

```powershell
python doctorhide.py "паспорт.png"                     # картинка
python doctorhide.py "договор.docx"                    # docx -> md
python doctorhide.py "акт.pdf" --dpi 400               # плотнее OCR для скана
python doctorhide.py "решение.pdf" --mode judicial     # принудительно судебный акт
python doctorhide.py "папка\"                          # папка целиком
python doctorhide.py "docs\*.pdf" --report report.json # маска + JSON-отчёт
```

Ключи: `--mode auto|judicial|document`, `--ocr auto|always|never`, `--dpi`, `--placeholder`,
`--keep`, `--only`, `--ask`, `--keep-meta`, `--court-keep-ids`, `--report`, `--json`, `-o`.

Tesseract: ставится отдельно (`winget install UB-Mannheim.TesseractOCR`), русская модель
и конфиги лежат в `_tools\tessdata` и подхватываются автоматически.

## Проверка результата

- После обработки PDF переоткрывается и проверяется извлечённый текст: скрытых значений быть не должно
  (`leftover` в отчёте).
- Отдельно проверяются сырые потоки PDF, включая распакованные, — там значений тоже нет.
- Метаданные (автор, producer, даты) очищаются, если не указан `--keep-meta`.

## Ограничения

- ФИО определяются эвристиками: отчество, суффиксы фамилий, справочник имён, ролевые маркеры.
  Экзотическая фамилия без отчества и без маркера может не распознаться — критичные документы
  просматривайте глазами (или используйте `--ask`, чтобы видеть, что найдено).
- Правила «ключевое слово + значение» намеренно требуют рядом цифру/название, чтобы не съедать
  заголовки («налогоплательщика», «Паспорт гражданина Российской Федерации» в сноске).
- OCR ошибается на косых и шумных сканах; при `--ocr always` координаты берутся из распознанного текста.
- В сканах и картинках плашки выжигаются в растре: пиксели уничтожены, но вместе с ними может
  пострадать фон под плашкой (линия рамки и т. п.).
- Даты событий (не рождения) по умолчанию не скрываются — это не персоналия.
